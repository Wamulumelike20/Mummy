# Mum's 50th Golden Jubilee Website

A responsive, interactive front-end birthday website built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser.

## Photos
The six supplied photos are in `assets/` and are already connected to the gallery/hero sections.

## Easy edits
- Birthday text: `index.html`
- Colours/layout: `style.css`
- Animations/interactions: `script.js`

The website includes:
- Golden Jubilee intro animation
- Animated 50 milestone
- Personal wishing cards for Mbe, Kui and Wam
- Interactive golden-star "Make a 50" section
- Photo gallery with lightbox
- Timeline and tribute
- Responsive mobile navigation
